Neon Streets — Midnight City: a 3D GTA-style open-world driving game (Three.js, fully offline, static files). Third-person chase camera, procedural city, 6 story missions, wanted stars with police chases and a helicopter, carjacking on foot, 4 procedural radio stations, and a localStorage save with Continue. Keyboard driving (WASD/arrows, Space handbrake), HUD with speed, stars, objective, money, health and a minimap.

## Play it

Serve the game/ folder with any static server and open game/index.html in desktop Chrome. No network requests, no build step.

## Run the entry program

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
